# _KALLPA SENSE: Sistema portátil inteligente para la conservación de hortalizas en la comercialización de alimentos._

KALLPA SENSE es un proyecto tecnológico que propone una alternativa para reducir el deterioro y las pérdidas de hortalizas durante su transporte, venta y almacenamiento temporal. Está orientado a productos como el tomate, el pimiento y la berenjena, que pueden perder calidad debido a las altas temperaturas, los golpes y las condiciones inadecuadas de conservación.

El proyecto consiste en el diseño de un prototipo simulado de una caja portátil con aislamiento térmico, bandejas extraíbles, compartimentos para bloques térmicos y un sistema de monitoreo ambiental basado en sensores de temperatura y humedad y un microcontrolador ESP32.

## Objetivo

Diseñar y simular una solución tecnológica que permita monitorear las condiciones internas de una caja de conservación y evaluar su potencial para mantener condiciones más estables que las de un recipiente convencional.

## Componentes propuestos

- **Caja portátil con aislamiento térmico:** busca reducir el intercambio de calor con el ambiente.
- **Bandejas perforadas y extraíbles:** permiten organizar los productos y reducir el amontonamiento.
- **Bloques térmicos desmontables:** ayudan a absorber parte del calor que ingresa a la caja.
- **Sensores de temperatura y humedad:** permiten monitorear las condiciones ambientales internas.
- **Microcontrolador ESP32:** se propone para integrar los sensores y gestionar la recopilación de datos.
- **Registro de datos:** permite observar los cambios de temperatura y humedad durante las pruebas simuladas.

## Alcance del prototipo

El proyecto se encuentra en una etapa de simulación y diseño conceptual. Se busca representar el funcionamiento de los componentes y analizar las condiciones de conservación mediante datos simulados o generados para las pruebas, según la implementación disponible.

Los indicadores de evaluación previstos incluyen la temperatura, la humedad, la pérdida de masa y los cambios visibles de calidad de las hortalizas. Los resultados de una simulación no equivalen a pruebas realizadas con alimentos en un prototipo físico.

## Impacto esperado

KALLPA SENSE busca contribuir a la reducción de las pérdidas económicas de los comerciantes y del desperdicio de alimentos, promoviendo el aprovechamiento responsable de los recursos.

El proyecto se relaciona con los siguientes Objetivos de Desarrollo Sostenible:

- **ODS 2: Hambre cero**, mediante la búsqueda de alternativas para reducir las pérdidas de alimentos.
- **ODS 12: Producción y consumo responsables**, mediante la prevención del desperdicio y el mejor aprovechamiento de los productos.

## Estado del proyecto

**Estado:** Prototipo simulado / diseño conceptual.

**Público objetivo:** Comerciantes de mercados de abastos, puestos ambulantes y ferias locales.

**Productos de referencia:** Tomate, pimiento y berenjena.
